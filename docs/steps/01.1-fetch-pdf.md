# Step 01.1: Fetch one PDF

**Goal:** download one source document (invoice, purchase order or receipt) for an order, and keep it on disk so it's downloaded only once.

## Files

| File | What it is |
|---|---|
| [`src/three_way_match/fetch.py`](../../src/three_way_match/fetch.py) | `fetch_pdf(kind, order_id)` and a small command-line entry point |
| [`tests/test_fetch.py`](../../tests/test_fetch.py) | Caching and 404 behaviour, with a fake HTTP transport (no network) |
| [`pyproject.toml`](../../pyproject.toml) | Adds `httpx`, the HTTP client |

## Commands and output

```
$ uv run python -m three_way_match.fetch invoice 10250
invoice 10250: data/pdfs/invoice_10250.pdf (1,976 bytes), header b'%PDF-'

$ uv run python -m three_way_match.fetch invoice 10250   # second run
invoice 10250: data/pdfs/invoice_10250.pdf (1,976 bytes), header b'%PDF-'
uv run python -m three_way_match.fetch invoice 10250  0.06s user 0.02s system 92% cpu 0.087 total

$ uv run python -m three_way_match.fetch invoice 99999
invoice 99999: not found (404)

$ uv run pytest -q
..                                                                       [100%]
2 passed in 0.03s
```

## What happened

1. `fetch_pdf` looked up the dataset for `invoice` (`northwind_invocies`, misspelled in the source dataset) and built the file name `invoice_10250.pdf`.
2. It asked Hugging Face for `https://huggingface.co/datasets/AyoubChLin/northwind_invocies/resolve/main/invoice_10250.pdf`. That URL redirects to a storage server, so the client follows redirects.
3. It saved the 1,976 bytes to `data/pdfs/`. The first five bytes, `%PDF-`, are the signature every PDF starts with, so the download is a real PDF and not an error page.
4. The second run found the file on disk and made no network call, which is why it took under 0.1 s.
5. Order 99999 doesn't exist, so Hugging Face answered 404 and `fetch_pdf` returned `None` instead of raising. A missing receipt or PO is a normal business case (documents arrive in any order), not a crash.
6. The tests swap the real network for `httpx.MockTransport`, so they check the logic without depending on Hugging Face being up.

`data/` is in `.gitignore`: downloaded PDFs never go into git.

**Why it matters next:** step 01.2 turns this PDF into page images, because the parser reads images, not PDFs.
