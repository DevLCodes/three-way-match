# Step 00.1: Create the repo

**Goal:** an empty, runnable Python project with a test runner, under git, published as a public GitHub repo.

## Files

| File | What it is |
|---|---|
| [`pyproject.toml`](../../pyproject.toml) | Project metadata, Python >= 3.13, `pytest` as a dev dependency, `uv_build` as the build backend |
| [`uv.lock`](../../uv.lock) | Exact versions of every dependency, so every machine installs the same thing |
| [`.python-version`](../../.python-version) | Tells uv which Python to use (3.13) |
| [`src/three_way_match/__init__.py`](../../src/three_way_match/__init__.py) | Empty package marker; code goes under `src/` so tests import the installed package, not stray files |
| [`.gitignore`](../../.gitignore) | Keeps `.venv/`, caches, `.env` and downloaded `data/` out of git |
| [`CLAUDE.md`](../../CLAUDE.md) | The step-by-step working rules for this repo |
| [`docs/LLD.md`](../LLD.md) | Low-level design, grown one step at a time |
| [`docs/superpowers/specs/2026-11-05-three-way-match-rebuild-design.md`](../superpowers/specs/2026-11-05-three-way-match-rebuild-design.md) | The build plan: every step, in order |

## Command

```bash
uv run pytest
```

## Output

```
============================= test session starts ==============================
platform darwin -- Python 3.13.18, pytest-9.2.0, pluggy-1.7.0
rootdir: /Users/loki/Projects/three-way-match
configfile: pyproject.toml
collected 0 items

============================ no tests ran in 0.01s =============================
exit code: 5
```

## What happened

`uv run` created a virtual environment in `.venv/` with Python 3.13, installed the project and pytest from `uv.lock`, then ran pytest inside it. Pytest found the config in `pyproject.toml` and collected 0 tests, because none exist yet. Exit code 5 is pytest's code for "no tests collected"; it becomes 0 once step 01.1 adds the first test.

**Why it matters next:** every later step adds code under `src/three_way_match/` and a test under `tests/`, and this same command runs them all.
